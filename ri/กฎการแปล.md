# กฎการแปล: 蠱真人 → เซียนแห่งกู่

แปลจาก `gu_zhen_ren.md` (ต้นฉบับจีน) เป็นภาษาไทย แล้วต่อท้ายใน `เซียนแห่งกู่.md`
ยึดสำนวนของตอนที่ขัดเกลาแล้ว (ตอนที่ 58–76) เป็นหลัก ตอนต้นเรื่อง (1–10) แปลผ่านฉบับอังกฤษ และยังมีสำนวนแปลตามอังกฤษหลงเหลืออยู่ ไม่ควรเลียนแบบ
ใช้คำศัพท์ตาม `ศัพท์เทียบจีน-อังกฤษ-ไทย.md` ทุกครั้ง ฉบับอังกฤษ (`Reverend Insanity Vol*.md`) ใช้เทียบความหมายเมื่อจีนกำกวมเท่านั้น ไม่ใช้เป็นต้นฉบับ

## 1. หลักการใหญ่

1. **แปลจากจีนเป็นหลัก** ความหมาย ลำดับเหตุการณ์ และน้ำเสียงต้องตรงกับจีน ห้ามเติมเนื้อหา คำอธิบาย หรืออารมณ์ที่ต้นฉบับไม่มี
2. **กระชับ ไม่แปลทีละคำ** ภาษาจีนมีคำซ้ำ คำขยาย และคำเชื่อมมาก ให้ตัดส่วนที่ภาษาไทยไม่ต้องใช้ทิ้ง เช่น 地 / 著 / 了 / 一聲 / 一下 / 頓時 / 猛地 ที่ซ้อนกันหลายตัว
   - 王大慢慢地閉起雙眼，心中默念一聲。→ หวังต้าหลับตาช้าๆ เรียกกู่ในใจ
   - 他剛要察看，但早已經晚了。→ เขากำลังจะตรวจดู ทว่าก็สายเกินไป
3. **อ่านแล้วเป็นไทย ไม่ใช่ภาษาแปล** หลีกเลี่ยงโครงสร้างแบบอังกฤษ
   - ไม่ใช้ประธานหุ่น "มัน" (✗ มันเป็นเรื่องปกติที่… → ✓ เป็นเรื่องปกติที่…)
   - ไม่ใช้ "ถูก" กับเหตุการณ์ที่ไม่ใช่ความทุกข์โดยไม่จำเป็น (✗ พิธีถูกจัดขึ้น → ✓ จัดพิธี)
   - ไม่ซ้อน "ซึ่ง / ที่ / ของ" ยาวเหยียด ตัดเป็นวลีสั้นแทน
   - ละสรรพนามได้เมื่อประธานชัดจากบริบท (เขา…เขา…ของเขา → เหลือครั้งเดียว)
4. **ความยาวประโยคเลียนจังหวะจีน** ประโยคสั้นตัดฉับในฉากต่อสู้ ย่อหน้าบรรยายยาวในฉากวิเคราะห์ ประโยคที่ต้นฉบับแยกเป็นย่อหน้าเดี่ยวเพื่อเน้น ให้แยกแบบเดียวกัน
   - 逃！→ ต้องหนี!
   - 他死了。→ เขาตายแล้ว
5. **คงการซ้ำเชิงวรรณศิลป์** เมื่อผู้เขียนตั้งใจซ้ำ ให้ซ้ำด้วย
   - 但是。／但是…… → ทว่า... / ทว่า...
   - 就注定舉世皆敵，就注定獨來獨往，就注定殺劫重重 → คงโครงสร้างซ้ำสามจังหวะ

## 2. ระดับภาษาและน้ำเสียง

- ใช้ภาษากำลังภายในกึ่งโบราณ อ่านลื่น ไม่เป็นราชาศัพท์และไม่เป็นภาษาพูดยุคใหม่
- คำที่ใช้บ่อย: ทว่า, ย่อม, มิ / มิได้, หาก, เหตุใด, ผู้ใด, สิ่งใด, ครู่หนึ่ง, บัดนี้, ดุจ, ราวกับ, พลัน, ชั่วพริบตา, จำต้อง, ฉะนั้นแล้ว
- เลี่ยงคำทันสมัยหรือคำทับศัพท์ เช่น โอเค, เซ็ง, เทคนิค, ข้อมูลเชิงลึก ยกเว้นต้นฉบับใช้คำสมัยใหม่โดยตั้งใจ (เช่น หน่วย 米 / 厘米 / 小時)
- เสียงบรรยายเย็นชาและเฉียบแบบผู้เขียน โดยเฉพาะตอนแทรกปรัชญาของฟางหยวน ให้ใช้ประโยคสั้น หนักแน่น เหมือนคติพจน์
  - 殺人者，人恆殺之。→ ผู้ฆ่าคนย่อมถูกคนฆ่า
  - 為理想而死，那是蠢貨。為理想而苟且偷生的活著，那才是勇士！→ ตายเพื่ออุดมคติคือคนโง่ มีชีวิตอย่างอดสูเพื่ออุดมคติต่างหากคือผู้กล้า!
- คำหยาบหรือคำสบถ แปลให้แรงพอกันในสำนวนไทยยุทธภพ
  - 該死 / 可惡 → บัดซบ
  - 去他嘛的榮耀、名譽和面子！→ เกียรติ ชื่อเสียง และหน้าตา ไปตายที่ไหนก็ไป!

## 4. ศัพท์เฉพาะ

- **ยึดอภิธานศัพท์** `ศัพท์เทียบจีน-อังกฤษ-ไทย.md` เสมอ ถ้าเจอคำใหม่ ให้ตั้งคำแปลแล้วเพิ่มลงอภิธานศัพท์ในหมวดที่ตรงกัน พร้อมคอลัมน์จีน อังกฤษ ไทย และหมายเหตุ
- **ชื่อกู่** ใช้รูป "กู่ + ความหมาย" (กู่แสงจันทร์, กู่ผิวหยก) ยกเว้นชื่อที่เป็นชื่อสัตว์ล้วนในอภิธานศัพท์ (จักจั่นวสันต์สารท, หนอนสุรา, ผีเสื้อยมวิถี)
- **กริยาเฉพาะระบบกู่**
  - 煉 / 煉化 / 煉製 / 煉成 (蠱) → **ขัดเกลา** (ไม่ใช้ "หลอม")
  - 融合 / 合為一體 → หลอมรวม
  - 修行 → ฝึกตน / ฝึกฝน
  - 修為 → ระดับพลัง (หรือละไว้ เช่น 他的修為是二轉 → เขาอยู่ระดับสอง)
  - 資質 → พรสวรรค์
  - 催動 (真元/蠱) → กระตุ้น
  - 魔道 / 正道 → วิถีมาร / ฝ่ายธรรมะ
  - 覺悟 (ในความหมายการยอมรับผลของเส้นทางที่เลือก) → ความเด็ดเดี่ยว / ความตระหนักรู้
- **หน่วยร้อยละพลังต้นกำเนิด** 成 = สิบส่วน: 一成 → สิบส่วน, 四成 → สี่สิบส่วน, 半成 → ห้าส่วน, 七成 → เจ็ดสิบส่วน
- **ระดับ** 一轉…六轉 → ระดับหนึ่ง…ระดับหก, 中階 → ขั้นกลาง ฯลฯ ตามอภิธานศัพท์ (二轉中階 → ระดับสองขั้นกลาง)
- **ชื่อคนจีนในเรื่อง** ถอดเสียงจีนกลางตามอภิธานศัพท์ เขียนติดกันไม่เว้นวรรค (กู่เยว่ฟางหยวน, เจี่ยจินเซิง)
- **บุคคลประวัติศาสตร์และวรรณกรรมจีนบนโลก** ใช้ชื่อที่คนไทยคุ้นเคย หากมีชื่อจีนแต้จิ๋ว/ฮกเกี้ยนที่ติดหู ให้ใช้รูปนั้น
  - 曹操 → โจโฉ, 韓信 → หานซิ่น, 越王勾踐 → เยว่อ๋องโกวเจี้ยน
  - ชื่อบทกวีถอดเสียง ใส่อัญประกาศเดี่ยว: 《將進酒》→ ‘เจียงจิ้นจิ่ว’
- **ชื่อสถานที่** ใช้รูป "ภูเขา/หมู่บ้าน + ชื่อถอดเสียง" (青茅山 → ภูเขาชิงเหมา, 白家寨 → หมู่บ้านไป๋)

## 5. ตัวเลขและหน่วย

- ในเนื้อเรื่องเขียนตัวเลขเป็นคำไทย: สามปี, ห้าร้อยปี, หลายสิบคน, สามสิบหกก้าว
- ต้นฉบับจีนในไฟล์นี้ถูกแปลงเลขจีนเป็นเลขอารบิกโดยอัตโนมัติ แม้แต่ในสำนวน ให้อ่านกลับเป็นคำจีนเดิมก่อนแปล
  - 請1邊玩蛋去 = 請一邊玩蛋去 → ไสหัวไปไกลๆ
  - 1點珠雪 = 一點珠雪, 一物降一物 อาจปรากฏเป็น 1物降1物
- 時辰 แปลงเป็นชั่วโมง (1 時辰 = 2 ชั่วโมง): 三個時辰 → หกชั่วโมง; 小時 → ชั่วโมง
- หน่วยเมตริกในต้นฉบับ (米, 厘米) → เมตร, เซนติเมตร เขียนเป็นคำไทย (ห้าเซนติเมตร, ครึ่งเมตร)
- หน่วยจีนโบราณ (寸, 斤, 兩, 畝, 刻, 里) ถอดเสียง (ชุ่น, จิน, เหลี่ยง, หมู่, เค่อ, ลี้) และใส่เชิงอรรถอธิบายเมื่อปรากฏครั้งแรก
- หัวตอนที่ต้นฉบับมีเลขอารบิก ให้เขียนเป็นคำไทยเมื่อตัวเลขนั้นเป็นส่วนของสำนวน (6轉本命春秋蟬 → กู่ชีวิตระดับหก จักจั่นวสันต์สารท)

## 6. สำนวน คำพังเพย และบทกวี

- สำนวนสี่คำ (成語) ให้แปลความหมาย ไม่แปลตามตัวอักษร ถ้ามีสำนวนไทยที่ตรงกันให้ใช้
  - 黃花菜都涼了 → อะไรๆ ก็สายเกินไป
  - 鞭長莫及 → ทำอะไรไม่ได้
  - 朝不保夕 → ไม่รู้ว่าจะเห็นพรุ่งนี้หรือไม่
  - 有心算無心 → ฝ่ายหนึ่งลอบโจมตีโดยมีการเตรียมพร้อม
  - 七葷八素 / 頭破血流 → ย่อเป็นความหมายหลักหรือตัดถ้าซ้ำความ
- สำนวนที่สร้างภาพดีและเข้าใจได้ ให้คงภาพไว้: 如毒蛇撲食 → ราวงูพิษฉกเหยื่อ, 滔滔江水都洗不淨 → แม้แม่น้ำเชี่ยวก็ชำระไม่หมด
- บทกวีหรือวรรคคู่ แปลให้มีจังหวะ เน้นภาพและความหมาย ไม่ต้องสัมผัสบังคับ
  - 朝如青絲暮成雪 → ยามเช้าเกศาดำขลับดุจเส้นไหม ยามค่ำคืนกลับหงอกขาวโพลนราวหิมะ
- หัวตอนที่เป็นวรรคคู่ ใช้วรรคคู่ภาษาไทยเว้นวรรคกลาง: 月下贈玉皮，地花藏白豕 → มอบผิวหยกใต้แสงจันทร์ บุปผาคลังดินซ่อนสุกรขาว

## 7. รูปแบบการจัดหน้า (Markdown)

### หัวเรื่อง
- บทใหญ่ (卷): `## บทที่ N ชื่อบท`
- ตอน (第N節): `### ตอนที่ N ชื่อตอน` ไม่มีโคลอน เว้นวรรคหนึ่งครั้งระหว่างเลขกับชื่อ
- ไม่ใส่ `<!-- source: ... -->` และหัวเว็บไซต์ของต้นฉบับ

### ย่อหน้า
- หนึ่งย่อหน้าต้นฉบับ = หนึ่งย่อหน้าไทย คั่นด้วยบรรทัดว่าง
- ต้นฉบับมักรวมสองย่อหน้าด้วยช่องว่างเต็มความกว้าง `　　` ให้แยกเป็นสองย่อหน้า
- ต้นฉบับบางแห่งตัดย่อหน้ากลางประโยค (เช่น จบบรรทัดด้วย `，`) ให้รวมกลับเป็นประโยคเดียว

### บทพูด ความคิด เสียง
- บทพูด: อัญประกาศคู่ตรง `"..."`
  - ผู้พูดและกริยาอยู่ก่อนหรือหลังบทพูดก็ได้ ไม่ใส่โคลอน: `กู่เยว่ป๋อยิ้ม "พี่ชายเจ้าเลือกกู่แสงน้อย…"`
  - 道 / 說 ที่ไม่มีน้ำหนัก ตัดได้ หรือใช้ กล่าว / พูด / เอ่ย
- ความคิดในใจ (ต้นฉบับใช้ “...” โดยไม่มีผู้ฟัง): `*'...'*` ตัวเอียงในอัญประกาศเดี่ยว
  - `*'ใช้พลังไปสิบส่วน เหลือสี่สิบ'* หวังต้าตรวจช่องว่างวิญญาณ`
  - ความคิดที่ยาวต่อเนื่องหลายย่อหน้า ให้ใส่ `*'...'*` ทุกย่อหน้า
  - การเรียกใช้กู่ในใจ (心中默念) ก็เป็นความคิด: `*'กู่เงาติดตาม'*`
- คำเปล่งเสียงสั้นๆ ของตัวละคร (啊啊啊！, 吼！) เป็นบทพูด: `"อ๊ากกกก!"`, `"โฮก!"`
- เสียงประกอบที่ตั้งเป็นย่อหน้าเดี่ยว (砰, 噗, 撲通, 嗖) เป็นตัวเอียงไม่มีอัญประกาศ: `*ตุ้บ*`, `*พรวด*`, `*ตุบ*`, `*ฉึก*`, `*วูบ*`
- คำเรียกกู่ออกเสียงในการต่อสู้ (石皮蠱！ตะโกน) เป็นบทพูด: `"กู่ผิวหิน!"`

### เครื่องหมาย
- ภาษาไทยไม่ใช้จุลภาคและมหัพภาค ใช้การเว้นวรรคแทน `，` และ `。`
- ใช้ `?` `!` `?!` ตามต้นฉบับ
- `……` ในประโยคและ `——` ที่แสดงการหยุดหรือลังเล → `...`
  - 這是——玉皮蠱? → "นี่คือ... กู่ผิวหยกหรือขอรับ?"
- `——` ที่นำเข้าสู่บทพูด (聲音傳來——) ตัดทิ้ง
- `……` ที่ตั้งเป็นย่อหน้าเดี่ยวเพื่อตัดฉาก → คงเป็น `……`
- 《書名》→ ‘ชื่อ’ ในอัญประกาศเดี่ยวโค้ง
- ไม้ยมก `ๆ` ติดคำหน้า แล้วเว้นวรรคก่อนคำถัดไป (`ค่อยๆ ขยับ`)

### ท้ายตอน
```
…ย่อหน้าสุดท้ายของตอน
___
-เชิงอรรถ 1 (ถ้ามี)
-เชิงอรรถ 2
___
คุยกับผู้เขียน:
ข้อความของผู้เขียนที่แปลแล้ว (ถ้ามี)
___

### ตอนที่ ถัดไป
```
- ตอนที่ไม่มีเชิงอรรถและข้อความผู้เขียน ปิดด้วย `___` บรรทัดเดียว
- เชิงอรรถขึ้นต้นด้วย `-` ใช้อธิบายหน่วยจีน สิ่งของทางวัฒนธรรม การเล่นคำจากอักษรจีน หรือความหมายของชื่อสถานที่ (`-ผานสือ = ศิลาแกร่ง`) เขียนเลขอารบิกได้ในเชิงอรรถ

### ข้อความผู้เขียน (ps / 作者的話)
- แปลเฉพาะข้อความที่เกี่ยวกับเนื้อเรื่อง ตัวละคร หรือมุมมองของผู้เขียน หรือข้อความที่สนุกต่อผู้อ่าน (ขอตั๋ว อันดับซานเจียง) ไว้ใต้หัว `คุยกับผู้เขียน:`
- ผู้เขียนใช้สรรพนาม "ผม" และหางเสียง "ครับ" ได้ เพราะเป็นเสียงนอกเรื่อง
- ตัดทิ้ง: รายชื่อผู้สนับสนุนยาวๆ ประกาศกลุ่มแชต ตารางอัปเดต และข้อความโปรโมตหนังสือเก่า

## 8. การจัดการข้อผิดพลาดในต้นฉบับ

ต้นฉบับจีนเป็นฉบับเว็บที่มีคำผิดและชื่อสลับ ให้แก้ตามบริบทโดยไม่ต้องทำเชิงอรรถ
- ชื่อผิด: 他王二暫時使用不了 (ตอนที่ 76) หมายถึง 王大 → หวังต้า
- คำพ้องเสียงผิด: 繞我一命 = 饒我一命 → ไว้ชีวิตข้า, 修養 = 休養
- คำเกิน: 蜂蠱碧風輪 → กู่ล้อลมหยก
- ชื่อกู่สองรูป (愛生離 / 愛別離) → ใช้รูปเดียวตามอภิธานศัพท์ (กู่พรากรัก) และบันทึกรูปทั้งสองในหมายเหตุอภิธานศัพท์
- ประโยคที่ต้นฉบับพูดผิดตรรกะชัดเจน (你對付不了你 → จัดการเจ้าไม่ได้) แปลตามความที่ตั้งใจ

## 10. ขั้นตอนการแปลแต่ละตอน

1. หาตอนในจีนด้วย `## 第N節` ตอนแรกที่พบ (ไฟล์จีนมีหลายภาค เลขตอนซ้ำกัน ตอนของภาคแรกอยู่ช่วงบรรทัดต้นๆ)
2. อ่านทั้งตอนก่อน แยกส่วน ps / ประกาศ / source ออก
3. ตรวจศัพท์ใหม่ เทียบอภิธานศัพท์ และตรวจฉบับอังกฤษเฉพาะเมื่อจีนกำกวม
4. แปลตามกฎข้างต้น
5. อ่านทวนเป็นภาษาไทยล้วน ตัดคำซ้ำ ตรวจการสะกด ตรวจว่าไม่มีความหมายหายหรือเกิน
6. เพิ่มศัพท์ใหม่ลงอภิธานศัพท์ และปรับหัวอภิธานศัพท์ ("ตอนที่ 1–N") ให้ครอบคลุมตอนล่าสุด
