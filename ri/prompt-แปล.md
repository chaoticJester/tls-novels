# Prompt ช่วยแปล เซียนแห่งกู่

คัดลอกข้อความในกรอบด้านล่างไปใช้ แล้วเปลี่ยน `{N}` เป็นเลขตอน (หรือช่วงตอน เช่น `77–78`)

```
แปลตอนที่ {N} ของนิยาย 蠱真人 เป็นภาษาไทย แล้วต่อท้ายไฟล์ เซียนแห่งกู่.md

## ไฟล์ที่ต้องใช้
- กฎการแปล.md : กฎสำนวน คำเรียกขาน ศัพท์ และการจัดหน้า ต้องอ่านทั้งหมดก่อนเริ่ม และทำตามทุกข้อ
- ศัพท์เทียบจีน-อังกฤษ-ไทย.md : อภิธานศัพท์ ชื่อคน สถานที่ กู่ และศัพท์ระบบ ต้องใช้คำแปลตามนี้เท่านั้น
- gu_zhen_ren.md : ต้นฉบับจีน **ใช้เป็นต้นฉบับหลักในการแปล**
  หาตอนด้วย `## 第{N}節` ตัวแรกที่พบ (ไฟล์มีหลายภาค เลขตอนซ้ำกัน ภาคแรกอยู่ช่วงต้นไฟล์)
- Reverend Insanity Vol1.md (และ Vol อื่นๆ) : ฉบับอังกฤษ **ใช้เทียบเมื่อมีปัญหาเท่านั้น**
  หาตอนด้วย `## Chapter {N} -`
- เซียนแห่งกู่.md : ฉบับไทย อ่านสองถึงสามตอนท้ายสุดก่อนแปล เพื่อให้สำนวนและความต่อเนื่องของเรื่องตรงกัน

## วิธีแปล
1. อ่านตอนภาษาจีนทั้งตอนให้จบก่อน แยกส่วนที่ไม่ใช่เนื้อเรื่องออก (ps, ประกาศ, `<!-- source -->`)
2. แปลจากภาษาจีนทีละย่อหน้า ความหมาย ลำดับ และน้ำเสียงต้องตรงกับจีน ไม่เติมหรือตัดเนื้อหา
   แต่ตัดคำซ้ำ คำเชื่อม และคำขยายที่ภาษาไทยไม่ต้องใช้ ให้อ่านแล้วเป็นภาษาไทยที่ลื่นไหล
3. เปิดฉบับอังกฤษเทียบ **เฉพาะเมื่อ**
   - ภาษาจีนกำกวม หรืออ่านได้หลายความหมาย
   - สงสัยว่าต้นฉบับจีนพิมพ์ผิด ชื่อสลับ หรือขาดคำ
   - เจอสำนวน คำแสลง หรือการอ้างอิงที่ไม่แน่ใจความหมาย
   - เจอชื่อกู่ ชื่อคน หรือศัพท์ใหม่ที่ยังไม่มีในอภิธานศัพท์ (ดูว่าฉบับอังกฤษใช้คำใด เพื่อใส่คอลัมน์อังกฤษ)
   ถ้าจีนกับอังกฤษขัดกัน **ให้ยึดจีน** ยกเว้นจีนผิดอย่างชัดเจนจากบริบท
   ห้ามเอาประโยค สำนวน หรือคำอธิบายที่มีแต่ในฉบับอังกฤษมาใส่
4. ตรวจทานฉบับไทยอีกรอบ อ่านเป็นภาษาไทยล้วน: ตัดสำนวนแปล ตรวจการสะกดตามตารางในกฎการแปล.md
   ตรวจว่าความหมายไม่หายและไม่เกินจากจีน และตรวจศัพท์ให้ตรงกับอภิธานศัพท์
5. ต่อท้าย เซียนแห่งกู่.md ตามรูปแบบหัวตอน ท้ายตอน เชิงอรรถ และ "คุยกับผู้เขียน:" ในกฎการแปล.md
6. เพิ่มศัพท์ใหม่ลง ศัพท์เทียบจีน-อังกฤษ-ไทย.md ในหมวดที่ตรงกัน (จีน | อังกฤษ | ไทย | หมายเหตุ)
   และแก้ช่วงตอนในหัวไฟล์ให้ครอบคลุมตอนล่าสุด

## สิ่งที่ต้องรายงานเมื่อแปลเสร็จ
- ศัพท์ใหม่ที่เพิ่มลงอภิธานศัพท์ และเหตุผลที่เลือกคำแปล
- จุดที่ต้นฉบับจีนผิดหรือกำกวม ได้แก้หรือตีความอย่างไร และใช้ฉบับอังกฤษช่วยตรงไหน
- จุดที่จีนกับอังกฤษต่างกันอย่างมีนัย และเลือกแบบใด
- ข้อความผู้เขียน (ps) ที่แปลไว้หรือตัดทิ้ง
- ประโยคที่ยังไม่มั่นใจ ให้ยกจีนกับคำแปลมาให้ตรวจ
```
